A tiny Node program that writes one unsent micro-confession — a To: line naming who it was meant for, and the single line that was typed and never sent — to /output/entry.txt for make.fun's "Unsent: The Micro-Confession Sprint" bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
